Data URI Farbling Bypass check

Tests whether a data: URI loaded inside an <iframe> bypasses browser fingerprint-farbling (e.g. Brave Shields). Click the button below. This will:

  1. Read fingerprint-relevant values on this page (potentially farbled by Shields).
  2. Build a data:text/html,… URI whose inline script reads the same values.
  3. Load that URI in a hidden <iframe> — top-level navigation to data: is blocked in modern browsers.
  4. The iframe relays its readings back via postMessage (localStorage is unavailable because data: URIs have a null origin).
  5. This page compares both sets of values.
Note: Unlike blob: URLs (which share the creator's origin), data: URIs always have a null origin, so localStorage and BroadcastChannel cannot be used for the relay — only postMessage works.
Tip — verify with Brave Shields: To see the true unfarbled values as a baseline, try running this test twice:
  1. Shields UP (default) — run the test and note any mismatches.
  2. Shields DOWN — click the Brave lion icon in the address bar and toggle Shields off, then reload the page and run the test again. With Shields down both columns should show identical, real values, confirming what the farbled numbers are hiding.
A mismatch that disappears when Shields are down confirms the data: iframe is reading through the farbling layer.

How it works 
// 1. Build an HTML document whose inline script reads fingerprint
//    values and posts them to the parent via postMessage.
//    (localStorage is unavailable — data: URIs have a null origin.)
const innerDoc = `<!DOCTYPE html><html><body><script>
  parent.postMessage({
    type: 'farbling-result',
    data: {
      screen_width:        screen.width,
      screen_height:       screen.height,
      screen_availWidth:   screen.availWidth,
      screen_availHeight:  screen.availHeight,
      screen_availLeft:    screen.availLeft,
      screen_availTop:     screen.availTop,
      screenX:             screenX,
      screenY:             screenY,
      screen_colorDepth:   screen.colorDepth,
      devicePixelRatio:    window.devicePixelRatio,
      hardwareConcurrency: navigator.hardwareConcurrency,
      deviceMemory:        navigator.deviceMemory,
      canvas_fp:           getCanvasFp(),   // inline helper
    }
  }, '*');
<\/script></body></html>`;

// 2. Encode as a data: URI (top-level navigation is blocked, but
//    iframes accept data: src just fine).
const dataUri = 'data:text/html,' + encodeURIComponent(innerDoc);

// 3. Inject a hidden iframe with that URI as its src.
const iframe = document.createElement('iframe');
iframe.src = dataUri;
document.body.appendChild(iframe);

// 4. Main page listens for the relayed values.
window.addEventListener('message', (event) => {
  if (event.data?.type === 'farbling-result') {
    compareAndDisplay(mainPageValues, event.data.data);
  }
});
