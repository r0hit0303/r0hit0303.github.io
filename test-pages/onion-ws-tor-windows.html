ServiceWorker .onion WebSocket DNS leak outside Tor windows

What this tests

kOnionOnlyInTorWindows (default on) should stop .onion WebSockets outside Tor windows, with no DNS. A ServiceWorker can still open the same socket and reach the network stack. JavaScript will show ERROR in both cases — the leak is in the netlog, not the WebSocket result.

Vector:

How to test

  1. In the captured instance, open brave://settings/privacy and under Tor windows enable Only resolve .onion addresses in Tor windows (it is on by default in a clean profile).
  2. From this page (instructions are fine in Stable), copy the command and run it in Terminal. It launches a second Brave, not a tab in the browser you are reading now, and writes ~/Downloads/onion-ws-poc/netlog.json.
  3. Switch to that new instance (the banner there will say captured). Click Start Stage 1, wait for Finished, then Stop Stage 1.
  4. Quit the captured Brave so netlog.json is flushed. Reopen this page in any browser to load the file in Stage 2 — Start stays off unless the URL has capture=1.
  5. Stage 2: choose or drop Downloads/onion-ws-poc/netlog.json. That is when the verdict appears.
